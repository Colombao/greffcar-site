# Greff Car — novo site

Site estático (HTML, CSS e JavaScript puro) da Greff Car Multimarcas, Jaraguá do Sul/SC.

## Rodar localmente

```bash
npx serve .
```

## Estrutura

- `index.html` — página única
- `css/style.css` — estilos
- `js/data.js` — dados da loja e estoque (cópia do site atual em 13/11/2026)
- `js/app.js` — filtros, favoritos, simulador e links de WhatsApp

## Pendências

- Ligar o estoque ao sistema da loja (hoje é uma cópia fixa em `js/data.js`)
- Confirmar a taxa do simulador (1,89% a.m. é um valor de exemplo)
- Política de privacidade e aviso de cookies
